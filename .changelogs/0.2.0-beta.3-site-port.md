0.2.0-beta.3 + the NEI tabs + new features from the website.

## New
- Screenshots can be saved as a GIF with the wires flowing, or as a PNG with a transparent background. Annotations can be left out.
- Plans have a description. Edit it from the plan's tab or its tile in My plans.
- Select some cards and the overview shows only what goes in and out of them. You can turn it off in settings.
- My plans sorts by tier, power, machine count, name or date, and filters by tier, power and what a plan makes or takes.

## Better
- The overview's power tooltip shows the same power in amps for each voltage tier.

## Fixed
- The overview shows peak power for machines with a set count.
- Plans opened from a plan link, code or file keep their icon.

Install: `gtnhplanner-0.2.0-beta.3-site-port.jar` into `mods` (replace the old gtnhplanner jar).
